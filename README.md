## 📌 О репозитории

Добро пожаловать в официальный репозиторий практики на языке **C++** команды **KS54-Devs**! Здесь мы собираем наши лабораторные, практические задачи, алгоритмы и пет-проекты, которые пишем во время учебы. 

Цель этого репозитория — оттачивать навыки написания чистого кода, разбираться в сложных концепциях ООП, алгоритмах и готовить портфолио к будущему трудоустройству.

```text
