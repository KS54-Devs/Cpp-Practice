## 📂 Структура репозитория

### Папки

Каждая папка — это отдельная программа из нескольких файлов (`.cpp` и `.h`).

| Папка | Тема |
|-------|------|
| `AppPointFunc` | Указатели и функции: площадь круга через константные указатели |
| `ConvertMilFut` | Функции: перевод миль и футов в километры и метры |
| `DinamicMemory` | Динамическая память: `new` и `delete` |
| `Massiv` | Массивы и функция в отдельном файле |
| `MilFutKM` | Перевод миль и футов в километры и метры |
| `PointMass` | Указатели и массивы: динамический массив, `swap`, вывод и заполнение случайными числами |
| `PointerFunc` | Указатели в функциях: результат возвращается через указатель |
| `Sort_1` | Сортировка массива пузырьком |

### Отдельные файлы

Каждый файл — это одна небольшая программа.

| Файл | Тема |
|------|------|
| `AppCilka.cpp` | Ссылки |
| `AppIf.cpp` | Условие `if` и цикл `while` (сумма квадратов) |
| `AppPoint.cpp`, `AppPoint2.cpp`, `AppPoint3.cpp` | Указатели |
| `AppPointMassiv1.cpp`, `AppPoitMassiv.cpp` | Указатели и массивы |
| `CharMassiv.cpp` | Массивы символов |
| `Kvadrat1.cpp` | Сумма квадратов чисел |
| `PointPointMass.cpp` | Указатель на указатель, массивы |
| `PointerMass.cpp` | Указатели и массивы |

## 🚀 Как запустить

1. Скачай репозиторий:
   ```
   git clone https://github.com/KS54-Devs/Cpp-Practice.git
   ```
2. Открой папку с репозиторием в **Visual Studio Code**.
3. Открой терминал в VS Code (`Ctrl + ~`).

### Отдельный файл

Компилируем один файл:

```
g++ AppIf.cpp -o AppIf
```

### Папка с несколькими файлами

Сначала зайди в папку, потом скомпилируй **все** `.cpp` файлы сразу:

```
cd Sort_1
g++ *.cpp -o Sort_1
```

### Запуск программы

- Windows: `AppIf.exe`
- Linux: `./AppIf`



## 🛠 Требования

- Компилятор **g++** (на Windows — MinGW)
