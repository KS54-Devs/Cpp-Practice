Папки

Каждая папка это отдельная программа из нескольких файлов (.cpp и .h).

Папка	Тема	Что внутри
AppPointFunc	Указатели и функции	площадь круга: функция получает указатели на число π и радиус и возвращает результат
ConvertMilFut	Функции	перевод миль и футов в километры и метры, каждое действие в своей функции
DinamicMemory	Динамическая память	new и delete для одного числа и для массива, размер которого вводит пользователь
Massiv	Массивы	массив из нулей, вывод в цикле while и функция в отдельном файле Func.cpp
MilFutKM	Функции и заголовки	мили и футы в километры и метры, константы лежат в заголовочном файле
PointMass	Указатели и массивы	динамический массив: размер вводится с клавиатуры, заполнение и красивый вывод через setw, отдельные файлы Swap.cpp, printMass.cpp, randMass.cpp
PointerFunc	Указатели в функциях	площадь круга: результат функция записывает через третий указатель
Sort_1	Сортировка	массив случайных чисел и сортировка пузырьком, обмен чисел в Swap.cpp

<h2><img src="https://fonts.gstatic.com/s/e/notoemoji/latest/1f527/512.gif" width="30" height="30" alt=""> Как запустить</h2>

Скачай репозиторий и открой терминал в его папке (в VS Code это Ctrl + `):

git clone https://github.com/KS54-Devs/Cpp-Practice.git
cd Cpp-Practice

Отдельный файл собирается одной командой:

g++ AppIf.cpp -o AppIf

Папка состоит из нескольких файлов, поэтому собираем все .cpp сразу:

cd Sort_1
g++ *.cpp -o Sort_1

Запуск: на Windows AppIf.exe, на Linux ./AppIf.

Программы писались под Windows. В них есть команды chcp 65001 и pause, чтобы русский текст нормально отображался в консоли. На Linux всё запустится, но эти две команды выведут служебное сообщение.
